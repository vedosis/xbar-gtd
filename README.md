# XBar Plugins

This is my test project as a way to not only learn how to GoLang, but also `bazel` and `claude`.

Don't take it seriously. I practice the GTD methodology and use these plugins as an inbox to process.

## Plugins

### Github PRs
List all your open PRs and all PRs where you're tagged (directly or indirectly) as a reviewer.

### Google Doc Tasks [TODO]
List all unaddressed comments assigned to you in Google Docs.

### Notion.io Conversations [TODO]
List all conversations in your Notion.io workspace where there's an open comment assigned to you or an unresolved
comment you opened but aren't the last commenter.

### GMail [TODO]
List all unread emails in your Gmail inbox.

### Linear [TODO]
List all tasks requiring your attention in your Linear workspace.
